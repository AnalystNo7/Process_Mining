# T39: Управление глобальным шаблоном ролей

## Цель
Админ-страница для редактирования глобального справочника "базовых ролей" и шаблонов автоматической разметки подразделений. Используется как "стартовая точка" при создании проектов.

## Контекст
- `01_DATA_MODEL.md` таблица `core.global_role_templates`.
- `02_DOMAIN_LOGIC.md` раздел "Role mapping → автопредложение".
- T14 — Role mapping в проекте.

## DoD
- [ ] Эндпоинты (admin-only):
  - `GET /api/admin/global-role-templates` — список всех шаблонов.
  - `POST /api/admin/global-role-templates` — создание.
  - `PUT /api/admin/global-role-templates/{id}` — редактирование.
  - `DELETE /api/admin/global-role-templates/{id}` — удаление.
- [ ] Управление "паттернами автоматической разметки" — это словарь `{regex_pattern: role_name}` (например, `"Юридическ.*"` → `"Юридическое управление"`).
- [ ] React-страница `/admin/global-roles` — только для роли `admin`.
- [ ] UI:
  - Таблица ролей с возможностью редактирования.
  - Под ней — таблица паттернов (regex → роль).
  - Кнопка "Применить шаблон" для одного проекта (выбор проекта в модале → копирование текущих правил).

## Модель данных
```python
class GlobalRoleTemplate:
    id: int
    role_name: str           # "Юридическое управление"
    role_description: str
    is_active: bool
    sort_order: int

class GlobalRoleAutoPattern:
    id: int
    pattern: str             # regex, например "^Юридическ"
    role_name: str           # к какой роли отнести
    priority: int            # порядок применения
    is_active: bool
```

## Алгоритм автопредложения
```python
def suggest_role_for_department(department: str, patterns: list[GlobalRoleAutoPattern]) -> str:
    """Применяет паттерны по приоритету. Если ничего не сматчилось — 'Инициатор'."""
    for pat in sorted(patterns, key=lambda p: p.priority):
        if re.search(pat.pattern, department, re.IGNORECASE):
            return pat.role_name
    return "Инициатор"  # default
```
