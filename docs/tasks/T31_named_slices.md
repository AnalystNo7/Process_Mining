# T31: Именованные срезы

## Цель
Лёгкие пользовательские фильтры, сохраняемые с именем.

## Контекст
- `01_DATA_MODEL.md` таблица `core.named_slices`
- `03_API.md` раздел "9. Именованные срезы"

## DoD
- [ ] CRUD-эндпоинты для срезов (привязка к virtual_dataset_id).
- [ ] UI: страница `/virtual/:id/slices` со списком + создание/редактирование.
- [ ] При создании среза — форма с фильтрами (период, подразделения, роли, исполнители, активности, длительность кейса, with_rework).
- [ ] На дашборде есть dropdown "Применить срез" — фильтрует все виджеты.
- [ ] Срез = просто JSON фильтр, не материализуется.
- [ ] Удаление среза не должно ломать дашборд (приходится сбрасывать applied_slice_id в NULL).

## Реализация
- Сервис `slice_service.py` с CRUD.
- UI: компонент `SliceForm` с группами фильтров (Period, Departments, Roles, etc).

## Тесты
- `test_create_slice_validates_dataset_exists`.
- `test_apply_slice_to_dashboard`.

## Acceptance
Аналитик создаёт срез "Затяжные договоры >30 дней", применяет к дашборду — все виджеты пересчитываются на этой подвыборке.
