# CPS Process Mining

Платформа process mining для анализа узких мест (bottlenecks) и зацикленностей
(rework) в логах бизнес-процессов систем электронного документооборота
(СЭД — TESSA) и ITSM.

Путь данных: xlsx-выгрузка → физический датасет (маппинг колонок, проверка
качества) → виртуальный датасет, фиксирующий снапшоты разметки ролей и
SLA-правил, → дашборды и аналитика. Снапшоты дают воспроизводимость: цифры,
показанные руководству, не «уплывают» при изменении справочников, а ключевые
алгоритмы закреплены golden-эталоном (1328 кейсов, 25 606 событий, допуск ±1%).

Целевая аудитория — аналитики и руководители организации (10–20 пользователей);
источник данных — выгрузки СЭД и ITSM в формате xlsx.

## Возможности

- **Загрузка логов** — мастер импорта xlsx: превью файла, выбор листа книги и
  строки заголовков, сопоставление колонок, шаблон загрузки проекта, фоновый
  парсинг с индикацией прогресса
- **Качество данных** — health-check датасета (кейсы, события на кейс, доля
  повторов, заполненность подразделений и исполнителей) со статусом
  good/warning/poor и детальным отчётом
- **Разметка ролей** — справочник «подразделение → роль» с авто-подбором по
  глобальным шаблонам, версионированием и историей; анализ на уровне сырых
  операций или ролей (raw/role)
- **Виртуальные датасеты** — единица анализа со снапшотами ролей и SLA,
  фильтрами конфигурации и фоновым расчётом кэшированных метрик
- **Граф процесса** — DFG с фильтром по частоте переходов и лимитом узлов,
  панель ТОП-N путей с подсветкой и кросс-фильтром, зум, полноэкранный режим,
  экспорт PNG
- **Длительности и узкие места** — собственная длительность, длительность с
  учётом перехода (sojourn), длительность кейса; боксплоты, кривая накопления
  (CDF) с перцентилями, теплокарта «операция × подразделение», разложение
  «работа vs ожидание»
- **Повторы (rework)** — таблица ping-pong по операциям, глобальный процент
  повторов, сравнение длительности кейсов с повторами и без
- **SLA** — справочник правил проекта (роль, паттерн операции, единицы
  workdays/calendar_days/workhours/hours, допуск, целевой процент) и расчёт
  комплаенса по операциям с цветовой индикацией
- **Динамика** — количество операций и средняя длительность по периодам с
  переключаемой гранулярностью (день/неделя/месяц/квартал/год), поток кейсов,
  распределение событий на кейс
- **Дашборды** — шаблон «Стандартный PM» с вкладками (Стандартные метрики,
  Обзор, Процесс, Детали), 18 типов виджетов, drag&resize с сохранением
  раскладки, глобальные фильтры и именованные срезы
- **Drill-down и аннотации** — спуск от графа и таблиц к кейсам, событиям и
  составу ролей; текстовые пометки на узлах, рёбрах, кейсах и периодах
- **Рабочее время** — расчёт длительностей по производственному календарю РФ
  в рабочем окне 09:00–18:00 МСК
- **Экспорт** — граф процесса в BPMN 2.0 (открывается в Camunda Modeler /
  bpmn.io), изображения графа в PNG
- **Администрирование** — пользователи и роли (admin/analyst), журнал аудита,
  глобальный справочник ролей, резервное копирование и восстановление

## Стек

| Слой | Технологии |
|------|-----------|
| Приложение | Python 3.11, FastAPI, Uvicorn, Celery (фоновые задачи) |
| Данные | SQLAlchemy 2.0 (async) + asyncpg, PostgreSQL 15, Alembic, Redis 7 |
| Авторизация | JWT (python-jose, bcrypt), опционально LDAP/AD |
| Аналитика | pandas, workalendar (производственный календарь РФ), openpyxl |
| Интерфейс | TypeScript 5, React 18, Vite 5, Ant Design 5, Plotly.js, Cytoscape.js + dagre, react-grid-layout, TanStack Query, zustand |
| Качество | pytest (unit / integration / golden), ruff, mypy strict, ESLint, vitest |
| Инфраструктура | Нативная установка на Windows (без Docker), службы через nssm, Makefile; Linux/WSL — `Makefile.linux` |
